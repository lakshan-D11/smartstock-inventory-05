# SmartStock Inventory (05)

Create a professional, fully responsive Inventory Management System named SmartStock using React, TypeScript, and Tailwind CSS. Include a dashboard with stock summary cards and charts, product management with add/edit/delete, inventory tracking, categories, suppliers, purchase management, sales management, low-stock alerts, and reports. Use a modern blue-and-white design with a sidebar, search, filters, and realistic sample data. Make all major buttons and forms functional. Prioritize a polished frontend that works immediately, with sample data, and avoid requiring backend setup for the initial demo. Keep the code compatible with deployment to GitHub Pages.
